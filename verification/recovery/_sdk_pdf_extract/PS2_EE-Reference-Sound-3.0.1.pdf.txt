About This Manual 
This is the Runtime Library Release 3.0.1 version of the PlayStation®2 EE Library Reference - Sound 
Libraries manual.  
The purpose of this manual is to define all available PlayStation®2 EE sound library structures and 
functions. The companion PlayStation®2 EE Library Overview - Sound Libraries describes the structure 
and purpose of the libraries. 
Changes Since Last Release 
Chapter 6: Standard Kit Library/Sound System 
• Descriptions of the followi ng functions were added:  
    sceSkQuit() 
    sceSkSsQuit() 
• A description of master volu me setting was added to the "Description" of sceSkSsInit(). 
 
Related Documentation 
Library specifications for the IOP can be found in the PlayStation®2 IOP Library Reference manuals and the 
PlayStation®2 IOP Library Overview manuals. 
Note: the Developer Support Web site posts current developments regarding the Libraries and also 
provides notice of future documentation releases and upgrades.

sceSSyn_Init 
Initialize 
Library Introduced Documentation last modified 
libssyn 1.1 July 14, 2003 
Syntax 
int sceSSyn_Init(  
 sceCslCtx *module_context, Module Context address 
 unsigned int interval)  Period in which Atick() will be called (in microseconds) 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (must be called in an interrupt-disabled state) 
However, this function can be called in a multithreaded environment in an interrupt-enabled state if it does 
not conflict with other sceSSyn function calls. 
Description  
Initializes internal state. 
Reserves the entire scratchpad for a work area which will be used internally by the library. 
Return value  
If successful, returns sceSSynNoError (0). 
In there is an error, returns sceSSynError (-1).

sceSSyn_Init2 
Initialize 
Library Introduced Documentation last modified 
libssyn 2.8 July 14, 2003 
Syntax 
int sceSSyn_Init2(  
sceCslCtx *module_context, Address of Module Context 
unsigned int interval, Period of ATick() calls in (in microseconds) 
void *addr); Starting address of the work area used internally by 
the library 
 (size: 0x4000 bytes, 128 byte boundary) 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (must be called in interrupt-disabled state) 
However, this function can be called in a multithreaded environment in an interrupt-enabled state if it does 
not conflict with other sceSSyn functions. 
Description 
This function initializes internal state. 
The area specified by addr is used as an internal work area for the library. The address of this area must 
start on a 128-byte boundary and it must have a minimum size of 0x4000 bytes. 
Return value 
When the function succeeds, sceSSynNoError(0) is returned. 
If an error occurs, sceSSynError(-1) is returned.

sceSSyn_BreakAtick 
Interrupt sceSSyn_ATick() processing 
Library Introduced Documentation last modified 
libssyn 1.1 March 29, 2002 
Syntax 
int sceSSyn_BreakAtick(  
 sceCslCtx *module_context) Module Context address 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (must be called in an interrupt-disabled state) 
However, this function can be called in a multithreaded environment in an interrupt-enabled state if it does 
not conflict with other sceSSyn function calls. 
Description  
Interrupts the current sceSSyn_ATick() process that is executing.  
Processing is interrupted once an individual process (4 voices) ends.  
Also, after the process is interrupted, the output buffer is cleared and any voice generation in progress is 
terminated. 
Return value  
If successful, returns sceSSynNoError (0). 
In there is an error, returns sceSSynError (-1).

1-12    CSL Software Synthesizer - Interrupt Processing Functions  
PlayStation 2 EE Library Reference Release 3.0.1  -  Sound Libraries 
sceSSyn_ClearBreakAtick 
Cancel interruption of sceSSyn_ATick() processing 
Library Introduced Documentation last modified 
libssyn 1.1 March 29, 2002 
Syntax 
int sceSSyn_ClearBreakAtick(  
 sceCslCtx *module_context) Module Context address 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (must be called in an interrupt-disabled state) 
However, this function can be called in a multithreaded environment in an interrupt-enabled state if it does 
not conflict with other sceSSyn function calls. 
Description  
After sceSSyn_BreakAtick() has been called, sceSSyn_ATick() processing will be interrupted until 
sceSSyn_ClearBreakAtick() is called.  
sceSSyn_ClearBreakAtick() is typically called at the start of time measurement. When the permitted time is 
exceeded due to an interrupt or other cause, processing can be interrupted by calling 
sceSSyn_BreakAtick(). 
sceSSyn_BreakAtick() should really be used only in an emergency. Satisfactory results that control the load 
can normally be obtained for the output voices by limiting the maximum number of generated voices for the 
entire device or for each port. 
Return value  
If successful, returns sceSSynNoError (0). 
In there is an error, returns sceSSynError (-1).

sceSpu2MemInit 
Initialize libspu2m environment 
Library Introduced Documentation last modified 
libspu2m 2.4 March 29, 2002 
Syntax 
int sceSpu2MemInit(  
 void *table, Starting address of memory management table 
 unsigned int size, Size of memory management table  
(size divided by SCESPU2MEM_TABLE_UNITSIZE - 1) 
 unsigned int eff_opt) Whether or not to reserve effect work area 
SCESPU2MEM_NO_EFFECT Do not reserve effect work area 
SCESPU2MEM_USE_EFFECT Reserve effect work area 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (does not depend on interrupt disabled or enabled state) 
Description 
This function initializes the libspu2m environment. The memory management table is specified according to 
table and size. The memory management table is a global variable that must have an area of 
(SCESPU2MEM_TABLE_UNITSIZE *(size + 1)) bytes. Area can be allocated in SPU2 local memory only by 
a multiple of the size argument. 
The eff_opt argument can be used to specify whether or not an effect work area in SPU2 local memory 
should be considered. To use effects for a performance in the SPU2, be sure to use 
SCESPU2MEM_USE_EFFECT. SCESPU2MEM_NO_EFFECT can be specified if no effects will be used. 
The size that is allocated for the user area in SPU2 local memory will vary as follows according to the 
specification of eff_opt. 
eff_opt = SCESPU2MEM_USE_EFFECT 
 1,814,512 (0x1baff0) bytes 
eff_opt = SCESPU2MEM_NO_EFFECT 
 2,076,656 (0x1faff0) bytes 
To enable 32 areas to be allocated and to use effects, the following should be specified. 
/* Allocation of 32 areas */ 
static unsigned char tab[SCESPU2MEM_TABLE_UNITSIZE * (32 + 1)]; 
sceSpu2MemInit (tab, 32,      /* Number of areas: 32 */ 
              SCESPU2MEM_U SE_EFFECT); /* Effects are used */

sceSpu2MemAllocate 
Allocate SPU2 local memory 
Library Introduced Documentation last modified 
libspu2m 2.4 March 29, 2002 
 Syntax 
int sceSpu2MemAllocate(  
 unsigned int req_size) Requested size of area (bytes) 
Calling conditions 
Can be called from an interrupt handler 
Can be called from a thread 
Not multithread safe (does not depend on interrupt disabled or enabled state) 
 Description 
This function allocates an area in SPU2 local memory with a size specified by req_size. Due to SPU2 
limitations, if req_size is not a multiple of 16, it is rounded up so that it is a multiple of 16 bytes. 
The size argument of sceSpu2MemInit() will be used as an upper limit on the number of area allocations, 
that is, the number of pieces into which SPU2 local memory can be subdivided. If that limit is exceeded 
when sceSpu2MemAllocate is called, an error will be returned even if an unallocated area having a size of 
req_size remains. 
Return value 
If successful, returns the starting address of the allocated area (0 or more). 
If an error occurs, returns -1.
